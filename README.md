# Greendale Agropark - Attendance System Frontend

This repository hosts the official employee attendance kiosk web app for **Greendale Agropark**.

## Setup Instructions:
1. Ensure `index.html`, `manifest.json`, and `sw.js` are uploaded directly to the **root directory** of this repository (do not place them inside a subfolder).
2. Open `index.html` and replace `YOUR_WEB_APP_URL_HERE` with your deployed Google Apps Script Web App URL.
3. Enable **GitHub Pages** in your repository settings (`Settings > Pages > Deploy from main/root`).
4. Open the live URL on any browser, phone, or tablet. You can install it directly to your home screen as a standalone app!
